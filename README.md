# Montaperti per Windows

[**Scarica il client pronto da giocare**](https://github.com/rigorage/Montaperti-Download/releases/latest)

Nella release apri **Assets** e scarica lo ZIP che inizia con **Montaperti-Windows**. Estrai tutta la cartella e avvia **Montaperti.exe**. Puoi creare un collegamento sul Desktop.

Dopo questo primo download, il client controlla e installa gli aggiornamenti all’avvio. Non serve un account GitHub. Le partite in corso non vengono interrotte. Se sei offline o un download fallisce, resta disponibile la versione precedente.

Questo repository contiene solo i pacchetti distribuibili e il processo di pubblicazione. Il repository di sviluppo resta privato. Le modifiche approvate su main vengono distribuite dopo le verifiche automatiche.

I file Montaperti-app.zip e update.json sono usati dal programma di aggiornamento: per il primo avvio scegli lo ZIP Windows completo.
